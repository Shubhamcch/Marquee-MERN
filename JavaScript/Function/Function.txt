A first-class function means that functions are treated like any other value in JavaScript. You can:

Store them in variables
Pass them as arguments to other functions
Return them from other functions
Store them in objects or arrays
Example 1: Assign a function to a variable
const greet = function() {
  console.log("Hello!");
};

greet(); // Hello!
Example 2: Pass a function as an argument
function sayHi() {
  console.log("Hi!");
}

function execute(fn) {
  fn();
}

execute(sayHi); // Hi!
Example 3: Return a function
function multiplyBy(x) {
  return function(y) {
    return x * y;
  };
}

const double = multiplyBy(2);
console.log(double(5)); // 10







The rest operator (...) and spread operator (...) use the same syntax (...), but they serve opposite purposes.

Rest Operator	Spread Operator
Collects multiple values into one	Expands one value into multiple values
Used in function parameters and destructuring	Used in function calls, arrays, and objects
Packs values	Unpacks values
1. Rest Operator (...)

The rest operator collects the remaining elements into a single array.

Example 1: Function Parameters
function sum(...numbers) {
  return numbers.reduce((total, num) => total + num, 0);
}

console.log(sum(1, 2, 3, 4)); // 10

Here:

...numbers collects all arguments into the array numbers.
numbers becomes [1, 2, 3, 4].
Example 2: Array Destructuring
const [first, ...rest] = [10, 20, 30, 40];

console.log(first); // 10
console.log(rest);  // [20, 30, 40]
2. Spread Operator (...)

The spread operator expands an array or object into individual elements or properties.

Example 1: Array
const arr1 = [1, 2];
const arr2 = [...arr1, 3, 4];

console.log(arr2); // [1, 2, 3, 4]
Example 2: Function Call
const nums = [5, 10, 15];

console.log(Math.max(...nums)); // 15

Instead of:

Math.max(5, 10, 15);

...nums expands the array into separate arguments.

Example 3: Object
const user = {
  name: "John",
  age: 25
};

const updatedUser = {
  ...user,
  city: "New York"
};

console.log(updatedUser);
// { name: "John", age: 25, city: "New York" }
Easy Way to Remember

Rest = Collect

function demo(...args) {}
// Collects arguments into an array

Spread = Expand

const arr = [1, 2, 3];
console.log(...arr);
// Expands to: 1 2 3







Return Value and Early Return in JS

Return Value

In JavaScript, a function can return a value to the caller, and when a function reaches a return
statement, it stops executing and returns the value specified after the return keyword.

If a function does not return a value, the return value will be undefined. The return statement can be
used to send a value out of a function, and it can return any type of value, not just numbers.

. Early Return

Early return in JavaScript is a technique where a function exits as soon as a certain condition is met,
usually to handle an edge case or invalid input.
